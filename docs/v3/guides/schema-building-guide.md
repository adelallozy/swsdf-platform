Important note:
- `radioTiles` supports both single-value and multi-value modes.
- For multi-value usage, set `attrs.multiple: true` and use an array value with array-aware validation.
- See the `Radio Tiles` section in the [MasterForm Component Guide](./masterform-guide.md).
- For free-form string arrays such as `languages`, use `TagsInput` and keep the field value canonical as an array.
- See the `Tags Input` section in the [MasterForm Component Guide](./masterform-guide.md).
