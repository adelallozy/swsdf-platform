## Removal Checklist

1. Remove the route and any parent redirect that only existed for that route.
2. Remove header, footer, home page, and service card links to the route.
3. Search `src` for the route name, path, page component, and imported child components.
4. Delete only components with no remaining `src` imports.
5. Leave workspace/private routes and shared components in place when still referenced.
6. Run `npm run translations:audit` and remove only reviewed translation keys that are not source-used, dynamically translated from API data, or still needed by private/workspace pages.
7. Run a production build or record why it could not be run.
